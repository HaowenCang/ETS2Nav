## 一、实现（reminder.rs 扩展）

`GlosaConfig` + `GlosaAdvice` + `glosa_advice(distance, state, confidence, remaining, v_now, limit, cfg)`：

**窗口**（绿灯通行时间 [t1, t2]）：
- 红灯：`[remaining, remaining + G]`（remaining = 到绿灯开始；G = 绿灯时长）；
- 绿灯：`[0, remaining]`（remaining = 绿灯剩余）；
- 黄/未知/未验证：不输出。

**理论速度范围**：`d/t2 ≤ v ≤ d/t1`（§38 公式）。

**物理约束求交集**：
- 加速可达上限 `v ≤ sqrt(v_now² + 2·a·d)`（恒定加速度近似）；
- 限速 cap（当前限速；`limit ≤ 0` 不压）；
- 交集空 → `feasible=false`（"赶不上这轮绿灯"场景，不诱导加速）。

**低精度量化**（§38 不制造虚假精度）：下限 floor 到 5 km/h、上限 ceil 到 5 km/h
（示例 53.6~64.2 → 55~65 档显示；ceil 方向 epsilon 吸收 f32 边界误差——修复
60.000002 km/h 被误 ceil 到 65 的 bug）。

**数据源决策**：绿灯时长 G 以配置默认（15s）提供——dataset v2 仅存
signal_group_type profile 名（semaphore-profile.md 实证 interval 存在于 SII 定义，
但未写入 dataset，P3-01 免 v3 原则下不扩展 schema）；B2 T3 实测后校准。
