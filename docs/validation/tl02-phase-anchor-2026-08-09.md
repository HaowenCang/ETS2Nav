## 结论

1. **H1（全局时钟）排除**：相位不由 game.time/simulation_time 的绝对位置决定。
2. **H2（加载锚定）确认**：相位 = f(灯组加载时刻)，加载时刻由玩家移动史决定，无法先验计算。
3. 结合 TL-01（interval 秒 = 真实秒，simulation_time 1:1 驱动）：
   - **纯计算倒计时不可行**
   - **观测锚定 + 外推可行**：灯组可见时锚定一次相位 → 用 profile interval（真实秒）+ simulation_time 外推后续转换
4. **周期稳定性**：59.99s ±0.05%（6 周期漂移 <0.1s）→ 锚定后外推多周期仍可满足 ±1s 精度潜力。
