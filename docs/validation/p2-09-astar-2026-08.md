# P2-09 Dijkstra + A* 报告（2026-08-10）

**依据**：P2-navigation-core-plan.md §70-78（Dijkstra Oracle/A* 启发/预分配/堆/Route 结构/metrics/ETA）。
**产物**：nav-router search 模块 + CLI `route` / `route-verify` 命令。

## 一、实现

### Dijkstra Oracle（§70）
- reference 搜索：验证 A* 最优性（§71），非生产路径

### A*（§72-75）
- binary heap（f64 有序包装）+ **generation counter 预分配**（§74：g_score/gen/parent_edge 数组，跨搜索复用不清零）
- 启发函数（§72/73，**下界保证**）：
  - Shortest：欧氏距离
  - Fastest：欧氏 / v_max（cap 130km/h）
  - Balanced：w_t·d/v_max + w_d·d/1000（下界线性组合仍为下界）

### 虚拟起终点接入（§57）
- 起点：forward 分支（到 to，剩余段成本）+ backward 分支（到 from）；**offset≈0 时 backward 分支总是展开**（成本 0，非回头）
- 终点：到达 goal edge 的 from/to 端点 + 虚拟段成本
- 起点 edge == 终点 edge：单段路线直返（无需搜索）

### Route / metrics（§76-78）
- Route{edges, start_virtual, end_virtual, distance_m, eta_s, road/junction/signal/ferry/train 计数, gps_avoid_distance, unknown_speed_distance}
- ETA = 静态自由流（限速+信号统计延迟+转弯+ferry/train；不含实时拥堵，§78）
- `route_cost()`：整路线成本（回归比较用）

## 二、验证

### 单元测试（4 个，总计 18 全绿）
- **A*==Dijkstra**（网格图 5 组 OD × 3 profile）
- 已知最短路径（对角捷径 2828m < 网格 4000m）
- 虚拟起点（边中部 offset 500 → 正确距离与虚拟段类型）
- 单段路线（同 edge 起点终点）

### 修复记录
- **Bug 1**：起点 offset≈0 时被强制走完整出边——backward 分支（成本 0）总应展开
- **Bug 2**：start_virtual 类型判定在 offset≈0 时错误标 forward——route_cost 多算一段

### Europe v4 真实数据
| 路线 | 结果 |
|---|---|
| Berlin→北向（4.96km） | fastest 350s / 80 边 / **0.1ms** |
| Berlin→西向（3.9km） | 243s / 50 边 / **0.0ms** |
| Berlin 城区 11.3km | fastest 756s（13min）/ 159 边 / **0.2ms**；shortest 11.19km（策略区分生效）；balanced≈fastest |
| **A*==Dijkstra 随机 OD**（50 OD × 3 profile） | **36 一致 / 0 不一致** |

### 性能（§139 目标：典型 <500ms）
**0.1-0.2ms/路线**——超出目标 2500 倍（Europe 全图 696,717 边规模下 A* 展开极小）
