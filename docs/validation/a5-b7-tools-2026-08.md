## B3 实验流程（实机执行，约 15-30 分钟）

### TL-03 Warp 实验
1. 游戏运行 + semaphore-bridge 插件加载；`dotnet run -c Release --project tools/signal-lab/SignalLab`
2. 接近信号灯路口按 `S` 开始会话
3. **执行快速旅行或休息跳过**（sim 前进跳变）——自动检出（无需按键）；若为位置传送
   （goto），按 `R` 键手动标记
4. 观察跳变后信号灯相位行为；按 `S` 结束会话
5. `SignalLabAnalyze <samples.csv> <events.csv>` → `=== TL-03 Warp 检测 ===` 段：
   检出跳变处（wall/超额）+ **跳变点前后最近相位事件对照**——据此人工判定：
   warp 后信号灯按 sim 相位继续 → sim 时钟驱动；相位重置 → 局部锚定

### TL-04 Reset 实验
1. 会话中在信号路口**读档**（sim 倒退）——自动检出；手动确认按 `R` 键标记
2. `=== TL-04 Reset 检测 ===` 段：检出倒退处 + **reset 后相位事件序列**（倒退后相位
   归零/保持 → B3 判定）；`=== TL-04 手动标记与自动检测对照 ===` 段交叉核对
3. 注意：**快速旅行使 sim 前进（TL-03 机制），读档才触发倒退**

### TL-05 Special Profiles 实验
1. 经过特殊 profile 路口（sleep_time 夜间闪烁、blockable）时按 `P` 键标记
2. `=== TL-05 特殊 profile 路口标记 ===` 段：标记时刻 wall/sim/scale 证据
3. 判定（B3 人工）：对照标记时刻相位与时钟——sleep_time 夜间倒计时失效逻辑验证

## 判定语义（工具产出证据，判定归 B3 人工）

- TL-03 检出 = sim 超额推进（快速旅行/休息跳过候选）——对照前后相位事件判定时钟域
- TL-04 检出 = sim 倒退（读档候选）——对照倒退后相位序列判定归零/保持
- TL-01 相邻对分析**自动跳过 RST/PROF 标记**（防跨标记伪判定；Δsim 有符号差）
- 所有 `=== TL-0x ===` 段标题恒定输出（无检出时输出"无 xxx（非错误）"——machine-readable）
