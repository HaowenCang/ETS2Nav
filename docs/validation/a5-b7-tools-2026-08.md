| 工具 | 位置 | 用途 |
|---|---|---|
| signal-lab（采集） | `tools/signal-lab/SignalLab/` | 高频采样（100Hz）+ 按键事件标记 + CSV 输出 |
| signal-analyze（分析） | `tools/signal-lab/SignalLabAnalyze/` | 时钟域（TL-01）/相位锚定（TL-02）/warp（TL-03）/reset（TL-04）分析 |

## B3 实验流程（实机执行，约 15-30 分钟）

### TL-03 Warp 实验
1. 游戏运行 + semaphore-bridge 插件加载；`dotnet run -c Release --project tools/signal-lab/SignalLab`
2. 接近信号灯路口按 `S` 开始会话
3. **游戏内执行传送（warp）**——无需按键（warp 由分析侧自动检测：sim 跳变 vs wall×scale 期望偏差 >300ms）
4. 观察 warp 后信号灯相位行为；按 `S` 结束会话
5. `signal-analyze <samples.csv> <events.csv>` → 输出 `=== TL-03 Warp 检测 ===` 段（检出跳变处 + 与相位事件对照）

### TL-04 Reset 实验
1. 会话中在信号路口**读档/快速旅行/传送**——sim 倒退由分析侧自动检测（`=== TL-04 Reset 检测 ===`）
2. 手动确认时按 `R` 键标记（events kind=RST，与自动检测对照）
3. 判定：reset 时信号灯相位是否同步重置（对照 RST 时刻后的相位转换事件）

### TL-05 Special Profiles 实验
1. 经过特殊 profile 路口（sleep_time 夜间闪烁、blockable）时按 `P` 键标记（kind=PROF）
2. 分析输出 `=== TL-05 特殊 profile 路口标记 ===` 统计（标记数 + 与相位/时钟对照）
3. 重点：sleep_time 夜间倒计时失效逻辑验证（夜间闪烁时 sim 时钟行为）

## 判定语义

- TL-03 检出 = sim 超额推进（warp 候选）——warp 后信号灯若按 sim 相位继续 → sim 时钟驱动；若重置 → 局部锚定
- TL-04 检出 = sim 倒退——倒退后相位是否归零/保持，对照 RST 时刻
- 输出全部 machine-readable（`=== TL-0x ... ===` 段标题），分析侧判定后写入 B3 汇总报告
