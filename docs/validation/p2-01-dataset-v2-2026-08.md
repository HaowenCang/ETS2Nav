## 二、布局（v2 定稿）

routing.graph：magic(7)+version(2)+endianness+node_count+edge_count+geom_point_count；
nodes 20B；edges 35/39B（+geom_offset u32 + geom_count u16 + speed_limit i16 + road_class u8）；
geometry 12B/点。junction.graph：movement = id u32 + entry/exit + length + turn + sid +
group_type + geom_offset/count（36B+type）；geometry 区在 junction 区后。

## 三、调试记录（v2 两个关键坑）

1. **geom_offset 单位**：C# 曾写点数（Rust 期望坐标值索引）→ 统一 ×3（点数→坐标值）。
2. **movement off/cnt 在 gt 字符串之后**：Berlin 的 SignalGroupType 全空（UseProfile→null）
   使固定偏移 30/34 恰好正确；Germany 出现 "traffic_light_major/minor"（gt_len=19）后
   Rust 读到字符串字节（0x66666634 = "4fff" 垃圾）——读端修正为 30+gt_len 偏移。
   教训：**gt 空集掩盖布局假设错误**——smoke 应含非空 gt 样本（Germany 覆盖）。
