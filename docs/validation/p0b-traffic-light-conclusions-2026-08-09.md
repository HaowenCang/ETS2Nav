## 倒计时方案（V1）

```
灯组可见（加载窗口内）
   │
   ├─ 未锚定：STATE_ONLY（红/绿/黄，无秒数）
   │
   └─ 锚定：观测到任一次相位转换（R2G/G2R/黄灯）
         │
         └─ 段长学习（1 个完整周期）或 profile interval
               │
               └─ phase(t) = (t - t_anchor + φ0) mod C 外推
                     │
                     └─ 倒计时显示（±1s 目标，实测 ≤0.5s）
```

- 锚定输入：屏幕捕获视觉检测（PC 侧）或人工（实验阶段）
- 重载检测：R2G/G2R 间隔偏离周期整数倍 → 重新锚定（H2 自动处理）
- **遗留**：profile interval 名义值（如 (15,2,41,2)）与实测段长（24.1/2.9/32.1/0.9）不符——优先采用「锚定后段长学习」，profile 值仅作候选；需进一步验证被测路口与 profile 的映射
